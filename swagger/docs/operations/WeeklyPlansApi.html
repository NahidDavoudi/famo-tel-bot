planSave

Resolves the student from student_id / national_id / name+grade, creating one when missing, then stores the week date, notes, time slots and events. Each event may carry one or more topics. When no plan id is given and a plan already exists for the same student + week date, it is updated instead of duplicated.

URL

https://api.famoacademy.ir/api/v1/plans

HTTP Method

Response Type
