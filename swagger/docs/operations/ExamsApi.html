examGetDates

Distinct exam dates with aggregate stats. Students are automatically scoped to their own results (a `student_id` different from the token's linked student returns 403).

URL

https://api.famoacademy.ir/api/v1/exams/dates

HTTP Method

GET

Response Type

Parameters

  • Query: student_id

    محدود کردن به تاریخ‌های یک دانش‌آموز (برای شاگرد خودکار تحمیل می‌شود)

  • Query: page

    Page number

  • Query: per_page

    Items per page

examGetDetails

Per-subject breakdown for one student on one exam date. Students may only query their own `student_id` (otherwise 403); staff can query any.

URL

https://api.famoacademy.ir/api/v1/exams/details

HTTP Method

GET

Response Type

Parameters

  • Query: exam_date

  • Query: student_id

examGetStudents

Staff-only listing of all students who took an exam on a date.

URL

https://api.famoacademy.ir/api/v1/exams/students

HTTP Method

GET

Response Type

Parameters

  • Query: exam_date

  • Query: page

    Page number

  • Query: per_page

    Items per page
