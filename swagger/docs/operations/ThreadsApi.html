This is the API

botThreadDay

URL

https://api.famoacademy.ir/api/v1/bot/threads/day

HTTP Method

GET

Response Type

Parameters

  • Header: X-Bot-Role

    Acting role for the linked Telegram account

  • Header: X-Telegram-User-Id

    Telegram numeric user id

  • Header: X-Telegram-Chat-Id

    Telegram numeric chat id (must match the stored link)

  • Query: day

    Tehran date (defaults to today)

  • Query: student_id

    Required when acting as a supporter

  • Query: page

    Page number

  • Query: perPage

    Items per page (alternate casing)
